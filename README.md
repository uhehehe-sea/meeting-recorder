# 회의녹음 웹앱 (Meeting Recorder)

아침회의·현장회의 녹음용 단일 파일 웹앱. 모든 프로젝트의 녹음 시스템으로 쓸 수 있게 만든 v0.1.

## 열기

GitHub Pages: https://uhehehe-sea.github.io/meeting-recorder/

HTTPS에서만 마이크가 동작하므로 Pages 링크로 여는 것이 정식 사용법이다. 파일을 직접 열면(HTTP/file) 마이크 권한이 안 뜰 수 있다.

## v0.1 기능

- **마이크 옵션**: 자동 음량 조절(AGC), 브라우저 소음 제거, 에코 제거
- **녹음 중 소리 다듬기**: 90Hz 이하 저음 제거(하이패스), 컴프레서(작은 소리 키우고 큰 소리 누름), AI 소음 제거 RNNoise(실험 — CDN에서 불러오며 오프라인이면 건너뜀)
- **레벨 미터**: 녹음 중 입력 음량 표시
- **안건 구분 버튼**: 회의 중 새 안건이 시작되는 시점을 초 단위로 표시
- **실시간 텍스트**: 브라우저 음성 인식(Web Speech API, 한국어)으로 녹음 중 텍스트 표시 (Chrome 기준)
- **저장**: 정지하면 녹음 파일(음량 정규화 -1dB 기준, WAV) + 텍스트·안건구분 JSON을 다운로드 링크로 저장. 서버 업로드 없음 — 파일은 사용자의 기기에만 남는다.

## 사용법

1. Pages 링크를 연다.
2. 원하는 옵션을 켜고 끈다 (기본값: AGC·하이패스·컴프레서·정규화 켜짐).
3. "녹음 시작" → 마이크 권한 허용 → 회의 진행. 안건이 바뀌면 "안건 구분" 버튼.
4. "정지" → 녹음 파일 + JSON 다운로드 링크가 아래에 뜬다.
